# 切换至管理员模式

在 26.3 版本后，局域网联机无法启用命令，玩家无法将存档切换至管理员模式，Acovia 存档预留了两份存档元数据存放于存档目录内。

## 存档元数据

游戏默认模式以及存档的世界级元数据存放于存档的 `level.dat` 文件中，但 Acovia 存档的目录下同时存在两份不带 `old` 后缀的 `dat` 文件：

- `level.dat`：默认存档元数据，正常游玩使用。
- `admin-level.dat`：管理员模式元数据，对世界内进行调试时使用。

## 切换

将 `level.dat` 文件重命名为任意与其他文件不重名的名称，随后将 `admin-level.dat` 重命名为 `level.dat`，启动游戏即可使用管理员权限。

反之将原默认元数据文件命名为 `level.dat` 即可回到正常模式。
