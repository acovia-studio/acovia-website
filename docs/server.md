# 服务器介绍

Acovia 是一个以原版生存为核心的中世纪风格 Minecraft 服务器。没有复杂的模组门槛，也不急着把世界改造成另一款游戏；这里更在意地形、建筑和玩家之间慢慢长出来的关系。

## 服务器信息

| 项目 | 内容 |
| --- | --- |
| 版本 | 26.2 |
| 平台 | Java 版 |
| 验证 | 正版验证 |
| 模组 | 不限制模组加载器 |
| 地址 | `acovia.net` |

## 世界

主世界被刻意保护，资源采集集中在独立的资源维度。这样既能让建筑和地形保持完整，也不会限制玩家获取材料。

存档会定期公开。离开的人也能把自己的建筑留在世界里，后来的人仍可以路过、观看，或者在其中找到一点旧日的痕迹。

::: info 服务器节奏
Acovia 更新相对激进，版本、维度和玩法都会持续变化。重要变动会记录在[更新日志](/changelog)中。
:::

## 特殊玩法

### 资源维度

主世界不提倡挖矿和破坏地形。需要大量材料时，前往资源维度采集。

进入方式：主世界坐标 `(129, 70, 132)` 处右键告示牌。若告示牌不在，可以激活命令方块重新生成。

### Eroven

手持 Eroven 的玩家受到致命伤害时，会被立刻拉回安全区域。它是死亡不掉落的替代方案。

合成：花 + 钻石。

### 回溯卷轴

右键使用后回到主城。探索新维度或远行前，建议随身带一张。

合成：纸 + 末影珍珠。

### 资源管理局

位于 `(184, 71, 128)`，可以购买木材、石材等基础材料。

### 附魔商店

位于 `(319, 63, 71)`，可以购买通用附魔书。

## 加入服务器

需要 Java 版 Minecraft 和正版账号；不限制模组加载器。

服务器地址：

```txt
acovia.net
```

服务器版本：26.2。

遇到问题或想找人一起玩，可以加入服务器群聊：

<https://qm.qq.com/q/5xdg6qn8nS>

## 服务器规则

- 禁止在主世界挖矿、破坏地形和建筑。采集资源请前往[资源维度](#资源维度)。
- 小型生电机器请在资源维度制造。需要建造地狱门时，可以在主世界 `(1024, 1024)` 到 `(1536, 1536)` 之间建造。
- 允许宣传其他服务器，但禁止吹捧和拉踩。
- 加入服务器即表示已阅读并同意以上规则。
