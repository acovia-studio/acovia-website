# 服务器介绍

Acovia 是一个以原版生存为核心的中世纪风格 Minecraft 服务器。服务器不需要安装模组，也不限制模组加载器。世界分为三个维度，具体玩法见[服务器玩法](/server/gameplay)。

## 服务器信息

| 项目 | 内容 |
| --- | --- |
| 版本 | 26.3 |
| 平台 | Java 版 |
| 验证 | 正版验证 |
| 模组 | 不限制模组加载器 |
| 地址 | `acovia.net` |

## 加入服务器

需要 Java 版 Minecraft 和正版账号。在多人游戏中添加服务器，地址填 `acovia.net`。

服务器不限制模组加载器，客户端装有模组也能进入。

遇到问题，或者想找人一起玩，可以加入[服务器群聊](https://qm.qq.com/q/5xdg6qn8nS)。

## 存档

世界存档会定期公开，下载地址见[公共存档](https://repo.acovia.net/resources/vmcs)。

离开的玩家可以把建筑留在世界里。存档公开后，后来的人仍然可以下载、查看。

## 规则

- 主世界禁止挖矿，禁止破坏地形和建筑。采集材料请前往资源维度。
- 小型红石机器请在资源维度制造。
- 允许宣传其他服务器，但禁止吹捧和拉踩。
- 加入服务器即表示已阅读并同意以上规则。
